# BusBD - Bangladesh Bus Ticketing Website

A modern, responsive bus ticket booking website designed specifically for Bangladesh, featuring beautiful UI with Bangladesh-themed colors (green and red from the national flag).

## 🚌 Features

### User Authentication
- **Registration System**: Complete user registration with validation
- **Login System**: Secure login with email or phone number
- **Local Storage**: User data persistence across sessions
- **User Profile**: Basic profile management

### Bus Booking System
- **Route Selection**: Popular Bangladesh cities including Dhaka, Chittagong, Sylhet, Rajshahi, Khulna, Barisal, Rangpur, Comilla, Mymensingh, and Jessore
- **Real-time Search**: Dynamic bus search with loading states
- **Multiple Bus Types**: AC Business, AC Sleeper, and Non-AC options
- **Popular Routes**: Pre-configured data for major routes
- **Dynamic Generation**: Automatic bus generation for any route combination
- **Booking System**: Complete booking flow with confirmation

### User Interface
- **Modern Design**: Clean, professional interface with beautiful animations
- **Bangladesh Theme**: Green and red color scheme reflecting national identity
- **Responsive Design**: Mobile-first approach, works perfectly on all devices
- **Interactive Elements**: Smooth animations, hover effects, and transitions
- **Modal Systems**: Elegant login and registration modals

## 🚀 Getting Started

1. **Open the Website**
   ```bash
   # Simply open index.html in any modern web browser
   open index.html
   ```

2. **Register an Account**
   - Click "Register" in the navigation
   - Fill in your details (name, email, phone, password)
   - Agree to terms and conditions
   - Account is created automatically

3. **Search for Buses**
   - Select origin and destination cities
   - Choose your travel date
   - Click "Search Buses"
   - Browse available options

4. **Book a Ticket**
   - Login to your account
   - Select your preferred bus
   - Click "Book Now"
   - Receive booking confirmation
